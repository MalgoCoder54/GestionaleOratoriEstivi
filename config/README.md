# Configurazioni di esempio

I JSON qui presenti sono esempi da cui partire per compilare i seed SQL e documentare le scelte dell’oratorio. In produzione la configurazione runtime viene salvata in Azure SQL nella tabella `configurazione_eventi` o `configurazione_animatori_eventi`.

Prima dell’uso sostituire `EVENTO_ESEMPIO`, date, importi, classi, taglie, squadre e stati con valori approvati dall’organizzazione. Non usare questi file per conservare segreti o dati personali.
